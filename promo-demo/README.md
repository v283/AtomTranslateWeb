# Демо зі справжніх записів екрана

Hero сайту (`../assets/demo.js`) і промо-відео показують **змонтований запис справжнього застосунку**
в рамці телефона (без вигаданого UI). Статус-бар із запису обрізається й замінюється чистим.

## 1. Монтаж із записів
```bash
REC_DIR=~/Desktop/screens/video python3 build.py
```
`clips.tsv` — що вирізати: `id запис початок кінець швидкість розділ`. Приватні екрани (вибір файлу, галерея)
свідомо не включені. Скрипт сам оновлює розділи в `../assets/demo.js` і кодує
`../assets/demo/atom-demo.{mp4,webm,jpg}` для сайту, а також кадри в `frames-src/` для відео.

## 2. Відео для реклами (стиль `ATOM-STYLE.md`)
```bash
npm install && npx playwright install chromium
npm run render:16x9     # 1920×1080, 60 к/с
npm run render:9x16     # 1080×1920, 60 к/с
npm run render:16x9:en  # англійська версія (також 9x16:en)
```
Тексти — `video.js` (`TXT`), фони й сцени теж там. Папка в `.assetsignore` — на Pages не деплоїться.
