Импорт слов из Quizlet в Atom Translate

Инструкция  •  Сохраните PDF из Quizlet, импортируйте в веб-версии или в приложении

Экспорт в текст/CSV в Quizlet платный. Бесплатный обходной путь — собственная функция Quizlet Print, которая превращает любой набор в PDF. Atom Translate читает этот PDF и сам достаёт из него термины и переводы.

Импорт работает и в веб-версии на app.atomtranslate.com (сейчас в бете), и в приложении Atom Translate на Android и iOS. Шаги одинаковые.

Коротко:
  • На quizlet.com: откройте набор → ⋯ → Print → оставьте макет Table → сохраните PDF
  • Откройте Atom Translate — app.atomtranslate.com или приложение на телефоне
  • Откройте папку → ⋯ → Import from Quizlet → выберите PDF → проверьте → Import

1

Сохраните набор из Quizlet как PDF

Делайте это на компьютере или на Android — файл будет один и тот же. На iPhone это невозможно вообще; почему — ниже.

На компьютере

  1. Откройте набор на quizlet.com и нажмите ⋯ в правом верхнем углу.
  2. Выберите Print.
  3. В предпросмотре оставьте слева макет Table — именно его читает Atom Translate — и нажмите иконку загрузки на панели предпросмотра. Системное окно печати не нужно.

На Android — через Firefox

В Firefox есть полноценный режим Версия для ПК, поэтому страница печати Quizlet открывается как на компьютере — с кнопкой Download, которая сохраняет тот же табличный PDF. Другие браузеры на Android передают страницу системному окну печати, а оно даёт файл с другой вёрсткой.

  1. Откройте набор в Firefox и нажмите ⋮ в правом нижнем углу.
  2. Включите Версия для ПК — страница перезагрузится в десктопном виде.
  3. Нажмите ⋯ у набора, затем Печать.
  4. Оставьте макет Table и нажмите Download над предпросмотром. PDF сохранится в «Загрузки».

На iPhone и iPad — Quizlet не создаёт PDF

На iOS получить этот PDF нельзя: в приложении Quizlet для iPhone вообще нет пункта Print, а на quizlet.com в Safari загрузка со страницы печати не сохраняет пригодный файл. Это ограничение со стороны Quizlet, а не Atom Translate — мы можем только прочитать файл, который Quizlet согласится сгенерировать, а на iOS он его не генерирует.

Что делать: создайте PDF на компьютере или на Android, а затем либо импортируйте его в веб-версии — телефон вообще не понадобится — либо перешлите файл на iPhone и импортируйте в приложении. Сам импорт на iOS работает нормально; не работает только экспорт из Quizlet.

2

Импортируйте PDF в веб-версии

Откройте app.atomtranslate.com и войдите своим обычным аккаунтом. Если PDF на этом же компьютере — это самый быстрый путь, телефон не нужен.

Веб-версия в бете: большинство вещей работает, но возможны шероховатости. Приложение на телефоне (шаг 3) — полностью релизный вариант.

  1. В Library откройте папку, куда хотите добавить слова.
  2. Нажмите ⋯ → Import from Quizlet.
  3. Нажмите Choose exported PDF file... и выберите PDF. При желании включите Import with pictures, чтобы перенести и картинки — это заметно дольше.
  4. Проверьте распознанные пары «термин — перевод»; исправьте ошибки или уберите строку кнопкой ×.
  5. Нажмите Import [количество] words. Слова автоматически синхронизируются с телефоном.
3

Или импортируйте PDF в приложении

В приложении всё так же. Если PDF создан на компьютере, сначала перенесите его на телефон — письмом себе, через облако или AirDrop / Nearby Share.

  1. Откройте папку и нажмите ⋯ → Import from Quizlet.
  2. Нажмите Choose exported PDF file... и выберите PDF из «Загрузок» или «Файлов».
  3. На экране Review words снимите отметки с того, что не нужно.
  4. Нажмите Import [количество] words — слова сразу появятся в папке.

Советы

  • Всегда оставляйте макет Table — другие макеты могут распознаться неправильно.
  • На Android экспортируйте в Firefox с версией для ПК — получите тот же PDF, что и на компьютере.
  • PDF должен быть текстовым — снимок экрана с набором не подойдёт.
  • Проверьте список перед подтверждением; слова можно отредактировать и позже в библиотеке.

Если что-то не так

В меню нет «Import from Quizlet»

Открывайте меню ⋯ внутри папки, а не на главном экране библиотеки. Если пункта всё равно нет — обновите приложение или напишите в поддержку.

Части слов нет или они неправильные

Обычно PDF экспортировали не с макетом Table. Экспортируйте ещё раз с выбранным Table и попробуйте снова.

Atom Translate не может прочитать файл

Это должен быть настоящий PDF из функции Print в Quizlet — не снимок экрана, не документ Word и не переименованный файл.

У меня только iPhone

Quizlet на iOS вообще не создаёт этот PDF (см. шаг 1). Экспортируйте его на компьютере или на Android, а затем импортируйте в веб-версии или перешлите на iPhone.
