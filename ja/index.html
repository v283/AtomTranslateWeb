Atom Translate — Quizletの無料代替アプリ

Quizletのような無料アプリをお探しですか？Atom Translateは、単語カード、クイズ、書き取り、マッチング、○×、リスニングの6つの学習モードを中心にした、Quizletの無料代替アプリです。サブスクリプションも、有料の壁も、ロックされた学習モードもありません。

機能

新しい単語を本当に覚えるために必要なものすべて

Atom Translateは語彙を標準で端末内に保存するので、アカウントも通信も不要で使えます。クラウド機能は必要なときにいつでも利用できます。

オフライン優先の保存

フォルダ、セクション、単語、進捗は端末内のローカルデータベースに保存されます。学習を始めるのにアカウントは不要です。

クラウド同期（任意）

フォルダ、単語、進捗をすべてのデバイスで同期したいときは、サインインしてください。

コミュニティデッキ

フォルダを公開したり、他の学習者が共有したデッキをダウンロード・複製したりできます。進捗は自分のぶんだけ別に記録されます。

設定できる翻訳

自動で翻訳したり、設定で翻訳プロバイダを切り替えたり、手動モードですべての訳を自分で入力したりできます。

音声入力と音声読み上げ

端末に内蔵の音声機能で、単語を音声入力したり、発音を聞いたりできます。

データはエクスポート可能

語彙全体をいつでもCSVにエクスポートできます。単語がアプリに閉じ込められることはありません。

学習モード

単語を長期記憶に定着させる6つの方法

セッションごとにモードを切り替えるか、習熟度が上がるにつれてフォルダが6つのモードを順に巡るようにできます。

01

単語カード

原文と訳をめくりながら、それぞれの単語をどれだけ知っていたかを記録します。

02

クイズ

選択肢から正しい訳を選んで、すばやく思い出す力を試します。

03

書き取り

記憶をたよりに訳を入力します。最も定着しやすい方法です。

04

マッチング

制限時間内に、原文と訳をペアにします。

05

○×

単語と訳を見て、その組み合わせが正しいかどうかを判断します。すばやく見分ける練習になります。

06

リスニング

発音された単語を聞いて、聞こえたとおりに入力するか、正しい訳を選びます。

公開セクションのランキング

公開セクション全体をクイズ、書き取り、マッチング、○×、リスニングのいずれかで終えると、結果がそのセクションのランキングに載ります。順位は正解数、次に所要時間で決まります。自己ベストの更新や、共有デッキでの他の学習者との競争を楽しめます。

公開デッキ

できあいのデッキを探す

他の学習者が公開した単語リストを、教科書・ユニット・トピック・レベルで検索できます。どのデッキも全単語を載せたページとして開き、サインインは不要です。

  • すべての単語に訳と発音、作者が追加した場合は画像も付きます
  • デッキを6つのモードすべてで学習できます。アプリでもブラウザでも
  • 各セクションのランキングで他の学習者と競えます

FAQ

よくある質問

Atom Translateは本当に無料ですか？

はい。単語カード、クイズ、書き取り、マッチング、○×、リスニングの6つの学習モードに加え、ランキングとQuizletインポートもすべて無料で、有料の壁はありません。

Atom TranslateはQuizletとどう違いますか？

Atom Translateは、書き取りモードやマッチングモードを有料プランに閉じ込めず無料のまま提供するQuizletの無料代替アプリで、標準でオフライン動作し、アカウントも不要です。

Quizletのセットをインポートできますか？

はい。無料のQuizletインポートツールが、既存のQuizletのセットをすぐに学習できるフォルダに変換します。

Atom Translateにランキングはありますか？

はい。公開セクションごとに、クイズ、書き取り、マッチング、○×、リスニングのモード別ランキングがあります。セクション全体を終えると、正解数、次に所要時間の順で順位が決まります。

Atom Translateはどのプラットフォームで使えますか？

Atom Translateは、AndroidではGoogle Play、iOSではApp Storeから入手でき、最新のブラウザならapp.atomtranslate.comでも使えます。
